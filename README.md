# 🚗 City Cruise

Lekka gra samochodowa w przeglądarce, w stylu retro (widok z góry). Wsiadasz za kierownicę
czerwonego roadstera i przejeżdżasz przez miasto stylizowane na **Katowice** — od herbaciarni
**DoTea** koło **Galerii Katowickiej**, przez centrum i Rondo, aż do **mety** w Strefie Kultury.

## ▶ Zagraj

**[Kliknij tutaj, żeby zagrać](https://radoko.github.io/city-cruise/)**

## 🎮 Sterowanie

| Klawisz | Akcja |
|---|---|
| `↑` / `W` | gaz |
| `↓` / `S` | hamulec / wsteczny |
| `←` `→` / `A` `D` | skręt |
| `Spacja` | hamulec ręczny / drift |
| `H` | klakson |

Na telefonie: przyciski dotykowe na ekranie (gaz, hamulec, lewo/prawo).

## 🗺️ Mapa

Topologia stylizowana na Katowice: główna oś (al. Korfantego / ul. Dworcowa), **Rondo**,
**al. Roździeńskiego**, trasa średnicowa (DTŚ), rzeka **Rawa**, centrum z Rynkiem i Strefa Kultury.

## 🛠️ Technologia

Jeden plik `index.html` — czysty HTML5 Canvas + JavaScript, bez zależności.
Hostowane na GitHub Pages.

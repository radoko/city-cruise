# 🎸🚗 Rawa Blues Run — Katowice: Spodek → NOSPR

Gra przeglądarkowa w stylu **GTA2** (widok z góry). Prowadzisz czerwoną **Mazdę MX-5 NB**
ulicami Katowic, w Strefie Kultury koło **Spodka**. Masz **misję specjalną**: dojechać do
**NOSPR**. Kiedy tam dotrzesz — odbierasz **prezent urodzinowy** 🎁:
bilet na **Rawa Blues Festival 2026**.

## 🎟️ O festiwalu (prezent w grze)

**44. Rawa Blues Festival** — sobota **3 października 2026**, **NOSPR**, Katowice.
Po raz pierwszy od dekad festiwal przenosi się ze Spodka do NOSPR — więc trasa w grze
to dokładnie ta sama podróż, którą w 2026 robi cały festiwal. 🎶

- **Sala Koncertowa (18:00):** Nik West • D.K. Harrell • Shakin' Dudi / Irek Dudek Big Band • Martin Harley
- **Sala Kameralna (15:00):** Blues Junkers • Furman & Kapela Kare Konie • Red. Chirowski & Pan Wydro • Robert Kordylewski
